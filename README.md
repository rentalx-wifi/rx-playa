# RX Playa

**Музыка без подписок и без рекламы.** Форк [BitChord](https://github.com/kushagrasinghx/BitChord).

[English version](README.en.md)

YouTube Music · SoundCloud · Spotify · Яндекс Музыка · VK · локальные файлы
Всё в одном списке, с одним поиском. Где именно играет трек — решает приложение.

---

## Что умеет

▸ **RX Wave** — станция из ваших лайков. Свои треки как семя, радио каждого из
них как источник похожего, и жёсткий фильтр: знакомые артисты вперёд, не больше
двух треков подряд, никаких чужих slowed-перепевок, никакого глобального чарта.

▸ **Подмена источника** — YouTube не отдаёт трек: регион, возраст, удалён. Тогда
он ищется на остальных включённых источниках — тот же артист или длительность до
секунды. Молча ничего не подменяется: приложение говорит, откуда играет.

▸ **Оформление** — Material 3 из Pixel Music: палитра, Montserrat, скругления
8/16/24, парящий док, настройки карточками. Цвета из обоев (Material You) или
свой акцент.

▸ **Звук** — Automix и кроссфейд, bit-perfect, USB DAC, выбор PCM, эквалайзер,
Dolby Atmos, пространственное аудио, нормализация громкости, пропуск тишины,
скорость без изменения тона.

▸ **Мелочи** — текст песен с переводом и подсветкой строки, скачивание и офлайн,
Discord RPC, Listen Together (общая очередь), обложки-канвасы, плеер с очередью
и текстом на одном экране.

▸ **Аккаунт и импорт** — лайки, плейлисты и история подтягиваются из
подключённого сервиса; чужие плейлисты импортируются по ссылке; поиск умеет
идти по всем источникам сразу или по одному.

## В бете

Честно, чтобы не было сюрпризов:

1. **Обход замедления YouTube (zapret).** Нужен root. Скрипт переписан с нуля —
   раньше `su -c` съедал аргументы, и `nfqws` не запускался ни разу, — но на
   части прошивок он всё ещё не заводится. Это ожидаемо, а не баг «у вас одного».
2. **Виджеты.** Переносятся из Pixel Music, пока в работе. До тех пор работают
   старые: квадратный, широкий и пилюля.
3. **RX Wave иногда промахивается.** Подбор ещё доводится: фильтр режет явный
   мусор, но не застрахован от странных радио-выдач. Будет пофикшено в
   следующем патче.

## Установка

1. Открой [Releases](../../releases) и скачай последний APK.
2. Разреши установку из этого источника, поставь.

`arm64-v8a` · Android 8.0+ (`minSdk 26`) · пакет `com.dev.bitchord`

Подпись не менялась с первых сборок, поэтому новая версия ставится поверх
предыдущей: настройки, лайки и скачанное остаются на месте.

> APK в Releases появляются руками, так что если последний релиз старее — значит
> сборка ещё не выложена. Свежие сборки также висят в CI (Actions → build).

## Сборка

Нужны JDK 17 и Android SDK с `compileSdk 37` и build-tools 37.

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk

# debug
./gradlew :app:assembleDevDebug

# release, arm64
./gradlew :app:assembleDevRelease \
  -PbitchordAbi=arm64-v8a \
  -Pbitchord.bundleWear=false
```

Для подписанной сборки положите `keystore.properties` по образцу
[`keystore.properties.example`](keystore.properties.example) и передайте
init-script с подписью:

```bash
./gradlew :app:assembleDevRelease -PbitchordAbi=arm64-v8a \
  --init-script build/rx-local-signing.init.gradle
```

`keystore.properties`, `*.jks`, `local.properties` и `build/` в репозиторий не
попадают — они в `.gitignore`.

## Дисклеймер

Неофициальный клиент. Не связан с YouTube, Spotify, SoundCloud, VK или Яндексом.
Подписки не нужны, аккаунт используется свой. Проект не хранит и не
распространяет музыку.
