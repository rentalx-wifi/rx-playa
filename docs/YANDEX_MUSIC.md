# Интеграция с Яндекс Музыкой

Интеграция работает внутри Android-приложения Playa и не требует установленного APK Яндекс Музыки.

## Архитектура

- Вход выполняется во встроенном `WebView` на `oauth.yandex.ru` через implicit OAuth flow клиента Яндекс Музыки. Финальный `access_token` читается только из редиректа доверенного OAuth-хоста.
- Токен хранится в существующем `EncryptedSharedPreferences` (`AuthStore`) и исключён из Android Backup.
- `/account/status` проверяет токен и получает имя аккаунта/наличие Плюса.
- Ynison (`wss://ynison.music.yandex.ru`) даёт актуальные очередь, паузу, позицию, длительность и активное устройство. REST `/queues` намеренно не используется как источник текущего состояния: сохранённая очередь может оставаться после остановки воспроизведения.
- `POST /tracks` на `api.music.yandex.net` дополняет id текущего элемента названием, исполнителями, альбомом и обложкой.
- `/users/{uid}/playlists/list`, `/users/{uid}/playlists/{kind}` и публичные ссылки читают плейлисты аккаунта без Плюса. При импорте записи сопоставляются с каталогом YouTube Music по названию, исполнителю, альбому и длительности; результат сохраняется локально либо в аккаунт YouTube Music, если он подключён.
- `DiscordPresenceCoordinator` держит единственное Discord-соединение. Трек, играющий непосредственно в Playa, имеет приоритет; когда локальный плеер остановлен, используется валидный трек Яндекс Музыки.

## Аккаунт без Плюса

Модуль не запрашивает URL аудиопотока и не обходит ограничения подписки. Он читает только состояние и метаданные. Рекламные и другие инжектированные элементы Ynison, пустые ответы, `available=false`, ошибки доступа и элементы не типа `TRACK` очищают Rich Presence до следующего валидного трека.

Для появления текущего трека воспроизведение должно идти на любом устройстве аккаунта, поддерживающем Яндекс Музыку Connect: например, в веб-плеере, desktop-клиенте или на колонке. Отдельный Android APK Яндекс Музыки для входа и синхронизации не нужен.

Google-аккаунт не требуется для импорта: без него Playa создаёт локальный плейлист. Для оформления приложения доступен отдельный гостевой профиль с локальным ником и аватаром; он намеренно не считается Google-авторизацией и не открывает лайки, историю или облачную библиотеку YouTube Music.

Тот же общий конвейер импорта используется Spotify и публичными плейлистами SoundCloud. Playa не обрезает число треков: страницы источника читаются до конца, а запись в YouTube Music выполняется пакетами. Ограничения скорости и доступности самого сервиса всё равно применяются; SoundCloud Go+ и защищённое аудио не обходятся.

Вход Google открывает desktop-вариант `music.youtube.com` и перехватывает переходы на Google Play, чтобы мобильная страница не предлагала установить официальный APK вместо веб-клиента.

Главная страница использует Spotify-подобную компоновку: приветствие, фильтры «Все / Музыка / Плейлисты», компактную сетку быстрого доступа и горизонтальные подборки. Поиск имеет постоянные кнопки «Все площадки», YouTube, Яндекс Музыка, Spotify, SoundCloud, локальная библиотека и аддоны. Внешние результаты являются метаданными и перед воспроизведением сопоставляются с доступным треком YouTube Music; защищённые потоки других сервисов не копируются.

Персональная главная объединяет лайки и историю YouTube/Яндекса, лайки и содержимое всех плейлистов Spotify, локальную историю, локальные и импортированные плейлисты. SoundCloud и аддоны без официального API лайков влияют на профиль только через импорт и действия внутри Playa. Данные разных аккаунтов не смешиваются и удаляются с Home сразу после отключения источника.

Расчёт профиля и ранжирование выполняются вне UI-потока. Удалённые библиотеки загружаются только при открытом Home, обновляются не чаще одного раза в 15 минут и сохраняют последнюю рабочую выдачу во время обновления. Spotify умеет переключаться между API веб-плеера и стандартным `api.spotify.com`; это помогает при отказе отдельного endpoint, но не является прокси и не может обойти блокировку Spotify по IP или региону.

Автоматическая проверка и установка релизов исходного репозитория отключена: этот проект развивается как отдельный форк.

В v7 добавлен `RX Wave`: персональная волна с Home, волна конкретного трека из его меню и волна исполнителя с его страницы. Для исполнителя используется точный Mix-target YouTube Music, а при его отсутствии — радио от первого доступного трека. Это собственная очередь RX Music, а не попытка получить защищённый поток «Моей волны» Яндекса.

Переключение четырёх основных вкладок теперь анимируется коротким направленным slide/fade, сохраняет позицию каждого списка и приостанавливает тяжёлую анимацию обложек на время перехода. Системная настройка уменьшения анимаций оставляет мгновенное переключение.

В v8 исправлен выбор высокой частоты экрана на устройствах, которые игнорируют один лишь `preferredRefreshRate`, убраны регулярные лишние UI-обновления телеметрии и подготовлена R8-оптимизированная сборка вместо медленной debug-сборки. Для доменов Spotify, SoundCloud и YouTube добавлен DNS-over-HTTPS с системным fallback. Это помогает только при проблемах DNS и не заменяет VPN при IP/SNI/DPI-блокировке.

В v9 исправлен redirect OAuth Яндекс Музыки: официальный клиент возвращает токен на `music.yandex.ru`, а не на страницу `oauth.yandex.ru`. После входа Playa проверяет `/account/status` и сразу показывает имя аккаунта и наличие Плюса. Для внешних треков добавлен строгий fallback-поиск в обычном публичном YouTube, если каталог YouTube Music пуст в регионе пользователя; SoundCloud-поиск также дочитывает следующие страницы.

У Playa есть Media3/ExoPlayer, но API Яндекс Музыки не предоставляет стабильный аудиопоток бесплатному аккаунту. Поэтому эта интеграция не выдаёт недоступный поток за рабочее нативное воспроизведение и не блокирует существующий YouTube Music-плеер.

## Сборка

```bash
./gradlew :app:assembleDevDebug
```

Неофициальные REST/Ynison протоколы могут быть изменены Яндексом. Реализация сверена с открытыми спецификациями [MarshalX/yandex-music-api](https://github.com/MarshalX/yandex-music-api) и [jrfrigat/YandexMusic](https://github.com/jrfrigat/YandexMusic).
