# RX Music: SoundCloud, VK Music и YouTube Music

## Перенос без ключей API (v20)

В настройках аккаунтов доступны реальные действия импорта вместо кнопок входа,
которые не могут завершить OAuth без зарегистрированного приложения.

- **SoundCloud → Импорт из SoundCloud**: ссылка на публичный плейлист или профиль.
  Для профиля приложение показывает публичные плейлисты и отдельный пункт лайков.
  Все страницы выбранной коллекции загружаются без лимита в 100 треков; цикл
  пагинации или ошибка страницы останавливает импорт, а не выдаёт обрезанный
  результат за полный. Плейлисты сохраняются на устройстве с исходными
  SoundCloud-идентификаторами и публичными URL. Google-приватность к ним не
  применяется. Это доступ к публичным данным, **не вход в SoundCloud**.
- **VK Music → Импорт списка треков VK**: вставка строк `Исполнитель — Название`
  либо выбор своего файла UTF-8 TXT, CSV/TSV или JSON. CSV принимает колонки
  `artist`/`title` (также `Исполнитель`/`Название`), JSON — массив треков или
  `tracks`, `items`, `response.items`. Названия сопоставляются существующим строгим
  YouTube Music / публичным YouTube matcher; порядок и повторения сохраняются,
  ненайденные записи показываются отдельно. При Google-входе создаётся приватный
  YouTube-плейлист; иначе или при отказе записи — полный локальный плейлист.
  Размер входного текста ограничен 4 млн символов для защиты памяти, а не числом
  треков. Это перенос метаданных, **не доступ к приватной медиатеке VK**.
- **Импорт сессии YouTube Music**: если Google отклоняет встроенный WebView,
  пользователь входит в `https://music.youtube.com` в своём обычном браузере,
  копирует только заголовок запроса `Cookie` из браузерных инструментов
  разработчика и вставляет его в защищённое поле RX Music. Затем открывается
  YouTube Music без повторного Google-входа; нужно выбрать профиль и нажать
  «Использовать этот профиль». Аккаунт сохраняется в существующем зашифрованном
  хранилище только после проверки его API. Пароль, `Set-Cookie`, весь запрос,
  неоднозначные дубликаты и управляющие символы не принимаются.

Cookie — полномочия доступа к аккаунту, не обычные настройки. Используйте только
свою сессию, не присылайте её разработчику и не помещайте в архивы/логи. Поле
скрывает значения и запрещает снимки экрана; временное значение не попадает в
сохранённое состояние Compose. Получение cookie из обычного Chrome на телефоне
может потребовать удалённых инструментов разработчика либо браузера на ПК.
Ручной перенос не меняет политику Google и не гарантирует, что истёкшая или
отозванная сессия будет принята.

## SoundCloud

Публичные поиск, импорт и воспроизведение продолжают работать без аккаунта.
Официальный вход добавляет профиль, личные плейлисты, синхронизацию лайков и
официальный пользовательский API как первый путь разрешения потока.

SoundCloud считает все API-приложения конфиденциальными: даже мобильный PKCE
обмен требует `client_secret`. Поэтому секрет **никогда не помещается в APK**.
Android создаёт `state`, `code_verifier` и `code_challenge`, а Go backend только
обменивает одноразовый код и обновляет single-use refresh token.

1. Зарегистрируйте приложение SoundCloud (для выдачи новых API-ключей SoundCloud
   сейчас требует Artist Pro).
2. Укажите redirect URI строго `rxmusic://oauth/soundcloud`.
3. На backend задайте:

   ```text
   SOUNDCLOUD_CLIENT_ID=...
   SOUNDCLOUD_CLIENT_SECRET=...
   SOUNDCLOUD_REDIRECT_URI=rxmusic://oauth/soundcloud
   ```

4. При отдельном домене backend добавьте в `local.properties` сборки:

   ```properties
   RX_MUSIC_BACKEND=https://api.example.com
   ```

Официальная кнопка входа показывается только после положительной проверки
конфигурации backend. Без этих значений остаётся публичный импорт; если
конфигурация исчезла между проверкой и нажатием, открывается этот импорт.
Секреты из официальных чужих клиентов не извлекаются и не подставляются.

## VK ID и VK Music

VK ID подключён через внешний браузер и PKCE, без WebView и перехвата пароля.
Для сборки с реальным приложением задайте:

```properties
VK_ID_CLIENT_ID=12345678
```

Redirect scheme автоматически станет `vk12345678://vk.ru/blank.html`; package и
SHA-1 подписи dev/prod сборок должны быть добавлены в кабинете VK ID.

Обычный VK ID предоставляет профиль, но не музыку. Методам `audio.*` нужен
исключительный доступ, отдельно согласованный VK. После согласования включите:

```properties
VK_AUDIO_SCOPE_APPROVED=true
```

Без `VK_ID_CLIENT_ID` кнопка OAuth не показывается: доступны импорт списка
треков и открытие официальной VK Music. С зарегистрированным client ID, но без
разрешения `audio`, доступны только вход и профиль. VK-вкладка не выдаёт чужие
или извлечённые токены за интеграцию; поиск внутри RX Music
явно помечается как YouTube fallback. После одобрения `audio` результаты VK
получают собственную идентичность и перед воспроизведением строго сопоставляются
с доступной записью; защищённый поток VK не маскируется под прямой.

## Лайки и дизлайки

RX Music хранит единый локальный рейтинг для YouTube, SoundCloud, Spotify, VK и
локальной музыки. Лайки попадают в отдельную вкладку «Любимое», дизлайки
исключают запись и её дубликаты из рекомендаций. При доступном API лайк также
синхронизируется с сервисом (YouTube и подключённый SoundCloud); отсутствие
такой возможности не ломает локальное действие.
